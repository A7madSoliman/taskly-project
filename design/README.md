# Design Specifications & Tokens

This directory contains design tokens, Figma references, and UI guidelines for the Taskly project.

- `tokens/colors.json`: Curated color palette tokens (`actionBlue`, `slateNeutrals`, `semantic`).
- `tokens/typography.json`: Typography scales and font family definitions.
- `components.md`: Component design guidelines and visual layering principles.
- `figma.md`: Figma file links, key node IDs, and MCP inspection guidelines.
