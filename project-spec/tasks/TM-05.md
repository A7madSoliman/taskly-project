## Description

Allow users to reset their password securely using API.

### **Requirements**

### **Note: On this task you need to use a real email so you can test the full journey**

### 1. **Forgot Password Page (`/forgot-password`)**


- Create a page with:
    - Email input field
    - “Send Reset Link” button
- When the user submits:
    - Call API endpoint:

```
POST {{base_url}}/auth/v1/recover
Headers:
  apikey: <API_KEY>
  Content-Type: application/json
Body:
{
  "email": "user@example.com"
}
```

- 
    - Show a success message: `If an account exists with this email, we’ve sent a password reset link.`
    - Handle API errors (e.g., invalid email format, network error) gracefully.
    - Display a `Don't Receive An Email? Resend` button with a timer 5 minutes, so after 5 minutes should be enabled else the button should be disabled and use have only 3 trials
- ✅ **Notes**
    - Do **not** reveal whether the email exists — always show the same success message.
    - Disable the button while loading.

---

### 2. **Reset Password Page (`/reset-password`)**

- User will receive an email with a button when user click on it, will redirect to [`http://localhost:3000#access_token=...&refresh_token=...&type=recovery`](http://localhost:3000/reset-password#access_token=...&refresh_token=...&type=recovery)
- if you found `type=recovery` redirect user to `/reset-password` page and attach the `access_token` to it
- Extract the `access_token` from the url
- If `access_token` exists → show the **“Reset Password” form**.
- Otherwise, show an error message: `Invalid or expired reset link.`

---

### 3. **Reset Password Form**

- Fields:
    - New Password
    - Confirm Password
- Validation:
    - use the same validation on sign up form for password input
- On submit:
    
    ```json
    PUT {{base_url}}/auth/v1/user
    Headers:
      Authorization: Bearer <ACCESS_TOKEN>
      apikey: <API_KEY>
      Content-Type: application/json
    Body:
    {
      "password": "newStrongPassword123"
    }
    ```
    
- Show success message: `Your password has been updated successfully. You can now log in`
- Redirect to `/login` after 3 seconds.
