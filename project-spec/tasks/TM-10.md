## Description

### Implement “Project Listing” Page


### 1. Route Setup

- Create a new route: `/project`
- The route should load automatically after successful login or be accessible via the sidebar link labeled **“Projects”**.

### 2. API Integration

Use the following API to fetch the user’s projects:

**Endpoint:**

```
GET <base_url>/rest/v1/rpc/get_projects
```

**Headers:**

```json
{
	"apikey": "<API_KEY>";
	"Authorization": "Bearer <ACCESS_TOKEN>";
	"Content-Type": "application/json";
}
```

### Display Requirements

Each project item should show:

- **Project Title** (from `name`)
- **Description** (from `description`)
- **Created At** (formatted as `DD MMM YYYY`, e.g., `12 Oct 2025`)

### Empty State

‣

If the user has no projects:

- Display a friendly message: `You don’t have any projects yet.`
- Include a button: **“Create New Project”** → navigates to the “Add Project” page.

### Implementation Details

### 1. Loading State

- Show a loading skeleton cards while fetching data.

### 2. Error Handling

‣

    - **Other errors:** display error screen
