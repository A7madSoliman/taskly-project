# TM-30 — Update Task Details

## Metadata

- Task ID: `TM-30`
- Status: `To Do`
- Source: `project-spec/source/notion/Update Task Details 76f35e9fb65183a1912001ddaf2599c8.md`

## Description

Allow users to **update Task details directly from the Task Details modal**:

- Title
- Description
- Assignee
- Due Date
- Epic
- Status

All updates must:

- Be saved via API (**partial PATCH**)
- Reflect **immediately in UI (optimistic update)**
- Roll back on failure

---

# 🎯 Editable Fields & Behavior

## 1️⃣ Task Title

- Editable text input
- Pre-filled with current title
- **Required**

### Behavior

- Save on: **Blur**
- If unchanged → ❌ no API call
- If invalid:
    - Revert to previous value
    - Show error toast

---

## 2️⃣ Task Description

- Editable textarea
- Pre-filled
- Optional

### Behavior

- Save on: **Blur**
- Empty value → store as `null`
- Display fallback:
    
    ```
    No description provided
    ```
    

---

## 3️⃣ Assignee

- Clicking field → enters **edit mode**
- Shows **select dropdown**

### Options

- Project members only
- Include:
    - “Unassigned”

### Behavior

- Save **immediately on selection**
- Selecting:
    - User → assigns task
    - “Unassigned” → `assignee_id: null`

---

## 4️⃣ Epic

- Editable via **select dropdown**
- Pre-filled if exists
- Optional

### Behavior

- Save on change
- Only show epics within:
    - Current project

### Edge Cases

- If epic deleted while open:
    - Reset field to `null`

---

## 5️⃣ Due Date

- Editable date picker
- Optional

### Behavior

- Save on change
- Clearing date → `due_date: null`

### Validation

- Must be valid date
- Prevent past dates

---

## 6️⃣ Status

- Editable via dropdown

### Behavior

- Save on change
- Must match allowed enum:
    - `TO_DO`, `IN_PROGRESS`, `DONE`, etc.

---

# 🔗 API Details

## Endpoint

```
PATCH /rest/v1/tasks?id=eq.{task.id}
```

## Headers

```
apikey: <API_KEY>
Authorization: Bearer <ACCESS_TOKEN>
Content-Type: application/json
```

## Request Body (Partial Update)

Only send **changed fields**:

```
{
  "title":"Updated title",
  "assignee_id":"user_id_or_null",
  "due_date":"2026-02-10T23:59:00Z"
}
```

---

# 🔄 State Management

## Strategy: Optimistic Updates

### On Change

1. Store **previous value**
2. Update UI immediately
3. Disable field (loading state)
4. Fire API request

### On Success

- Keep new value
- Show success toast

### On Error

- Revert to previous value
- Show error toast:
    
    ```
    Failed to update task. Please try again.
    ```
    

---

# 🚫 Prevent Unnecessary Calls

- Compare **old vs new value**
- ❗ Skip API if unchanged
