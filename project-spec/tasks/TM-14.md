---

# **API Endpoint**

Use this Supabase REST endpoint to fetch project members:

```
GET <BASW_URL>/rest/v1/get_project_members?project_id=eq.<projectId>
```

**Headers:**

```
apikey: <API_KEY>
Authorization: Bearer <user-access-token>
Content-Type: application/json
```
