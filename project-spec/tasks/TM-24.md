## Description

### 🎯 Objective

Create a **Task Details Popup (Modal/Drawer)** that displays full task information when a user clicks on a task from:

- Epic Details Popup
- Tasks Board View
- Tasks List View

---

### 🎨 Design Reference

- Figma:[https://www.figma.com/design/zAwYa5nDWE2YirHYPpNabw/Tasks-Management?node-id=67-454&t=L7Jf026Stu5qCTd2-0](https://www.figma.com/design/zAwYa5nDWE2YirHYPpNabw/Tasks-Management?node-id=67-454&t=L7Jf026Stu5qCTd2-0)

---

### 🔗 Trigger Behavior

Open the popup when user clicks on:

- Task item in Epic popup
- Task card in Board view
- Task row in List view

---

### 🔗 API Integration

### Endpoint

```
GET /rest/v1/project_tasks?project_id=eq.{PROJECT_ID}&id=eq.{TASK_ID}
```

### Notes

- Both `project_id` and `task_id` are required
- Returns **single task (array with 1 item)**

---

### 📦 Data to Display

Render the following fields (based on API + Figma):

### 📝 Core Info

- Task Title
- Task Description

### 👤 Assignment

- Assignee (name + avatar)
- If null → “Unassigned”

### 📅 Metadata

- Due Date
- Created At
- Status (e.g., Todo / In Progress / Done)
- Reporter

### 🧩 Relations

- Epic ID (if exists)

---

### 🛠️ Requirements

---

### 1. Data Fetching

- Fetch task details **on popup open**
- Use `taskId` + `projectId`
- Do NOT fetch if no task selected

---

### 2. UI Behavior

- Modal or right-side drawer (based on Figma)
- Close actions:
    - Close icon
    - Click outside
    - ESC key

---

### 3. States Handling

### ✅ Loading

- Show skeleton or loader inside popup

### ❌ Error

- Message:
    
    > “Failed to load task details”
    > 

### 📭 Empty (edge case)

- Message:
    
    > “Task not found”
    > 

---

### 4. Date Formatting

- Format as:
    - `DD MMM YYYY` (e.g., `27 Mar 2026`)

---

### 5. Assignee Handling

- If:
    - `assignee_name` → display
    - `assignee_avatar` → show avatar
- Else:
    - Show “Unassigned”

---

### 6. Status & Priority UI

- Display as:
    - Colored badge (based on value)
- Example:
    - Todo → Gray
    - In Progress → Blue
    - Done → Green
