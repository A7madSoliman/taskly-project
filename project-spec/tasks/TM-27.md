## Description

## 📌 Description

Enable **drag & drop functionality** on the **Project Tasks – Board View** so users can move tasks between status columns.

When a task is dropped into a new column, its **status should be updated** accordingly using the backend API.

---

## 🧭 Scope

- Applies **only to Board View**
- Works within:

```
/project/[projectId]/tasks
```

---

## 🖥️ UI & UX Requirements

### 1️⃣ Drag & Drop Behavior

- Each task card should be **draggable**
- Each status column should be a **valid drop zone**
- User can:
    - Drag a task from one status column
    - Drop it into another status column
- After drop:
    - Task should visually move to the new column
    - Status change should be persisted via API

---

### 2️⃣ Drag & Drop Library

- Use a **well-maintained drag & drop package**
- You should:
    - Research and choose the **best suitable library** for React
    - Prefer libraries that:
        - Are actively maintained
        - Support accessibility
        - Perform well with lists/columns

---

## 🔗 API Integration

### Update Task Status

When a task is dropped into a new column, update its status using:

**Route**

```
/rest/v1/tasks?id=eq.<task_id>
```

**Method**

```
PATCH
```

**Headers**

- `apikey`
- `Authorization: Bearer <access_token>`
- `Content-Type: application/json`

**Request Body Example**

```json
{"status": "IN_PROGRESS"}
```

---

## 🔄 State Management

- Optimistically update the UI on drop
- If API request fails:
    - Revert the task to its original column
    - Show an error message or toast
