## Description

### Create a form that allows authenticated users to **add a new project**

## Requirements

The route for the page will be `/project/add`

### 1. UI Form

- Create a form with the following fields:
    - **Project Title** (`name`) — *required, min 3 characters*
    - **Description** (`description`) — *optional but should not exceed 500 characters*
- Include a **Create** button.
- handle the responsive across all screens

### 2. Validation Rules

- `name`: required, min length 3, max length 100
- `description`: optional, max length 500
- If validation fails, show inline error messages under each field.

### 3. API Integration

Use the following endpoint to add the project:

**Endpoint:**

```
POST <base_url>/rest/v1/projects
```

**Headers:**

```json
{
	"apikey": "<API_KEY>",
	"Authorization": "Bearer <ACCESS_TOKEN>",
	"Content-Type": "application/json"
}
```

**Body Example:**

```json
{
	"name": "Test new project 444",
	"description": "All design & implementation tasks"
}
```

- The `ACCESS_TOKEN` should come from the authenticated user.
- If the request is successful, clear the form and show a success toast (e.g., “Project created successfully”).
- If the request fails, show an error message with the returned error text (e.g., “Failed to create project: [error message]”).
