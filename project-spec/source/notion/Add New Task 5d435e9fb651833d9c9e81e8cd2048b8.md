### 📌 Description

Implement the **Create New Task** flow that allows users to create a task under a project (and optionally under a specific epic).

When the user clicks **“Add Task”** from the **Epic Detail Popup**, they should be redirected to a dedicated page where they can fill in task details and submit the task.

---

## 🔀 Navigation & Routing

- Trigger: User clicks **Create New Task** from Epic Detail Popup
- Route: `/project/[projectId]/tasks/new`
- If the user navigates from an Epic Detail Popup:
    - The **Epic** field should be **pre-filled** with the selected epic
    - The epic field remains editable

---

## 📡 API Integration

### Endpoint

```
POST /rest/v1/tasks
```

### Required Headers

- `apikey`
- `Authorization: Bearer <access_token>`
- `Content-Type: application/json`

---

## 🧱 Request Body

```json
{
	"project_id": "<project_id>",
	"epic_id": "<epic_id | optional>",
	"title": "<string>",
	"description": "<string | optional>",
	"assignee_id": "<user_id | optional>",
	"due_date": "<ISO timestamp | optional>",
	"status": "<status>"
}
```

## 📊 Status Values

Allowed values for `status`:

- `TO_DO`
- `IN_PROGRESS`
- `BLOCKED`
- `IN_REVIEW`
- `READY_FOR_QA`
- `REOPENED`
- `READY_FOR_PRODUCTION`
- `DONE`

Default value: `TO_DO`

on the frontend display them without underscore

## 🧠 UI Requirements

### 🔹 Epic Field

- Load epics for the current project
- Display options in this format: `<epic_id> <epic_title>`
- Max epic title length: **100 characters**
    - If exceeded → truncate and append `...`
- If navigated from Epic Detail Popup:
    - Auto-select the corresponding epic
- Epic selection is optional

---

### 🔹 Assignee Field

- Display a dropdown of **project members**
- Optional field

---

### 🔹 Due Date Field

- Date & time picker
- Optional field

---

### 🔹 Description Field

- Multiline text area
- Optional
