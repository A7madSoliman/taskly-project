**Route:**

`/project/[projectId]/epics/new`

**Goal:**

Implement a “Create Epic” feature that allows users to add a new epic to a project using the Supabase REST API, following the provided Figma design and validation rules.

---

# **Functional Overview**

A logged-in user who is a member of a project should be able to:

- Open the “Create Epic” page
- Fill in epic details
- Submit the form
- Create a new epic linked to the selected project

---

# **API Endpoint**

### Create Epic (REST API)

```
POST <base_url>/rest/v1/epics
```

### Required Headers

```
apikey: <api_key>
Authorization: Bearer <user-access-token>
Content-Type: application/json
```

### Request Body Example

```json
{
  "title": "Epic 8888",
  "description": "All design & implementation tasks",
  "assignee_id": "31c7891a-15d4-46aa-94f8-db0fb5642e15",
  "project_id": "298be621-59c7-4a62-ad2c-e640ff72135f",
  "deadline": "2025-12-30"
}
```

# **Form Fields & Validation**

| Field
 
 | Type
 
 | Required
 
 | Validation Rules
 
 |
| --- | --- | --- | --- |
| Title
 
 | Text input
 
 | ✅ Yes
 
 | Required, min 3 characters
 
 |
| Description
 
 | Textarea
 
 | ❌ No
 
 | Optional
 
 |
| Assignee
 
 | Select
 
 | ❌ No
 
 | Project member list
 
 |
| Deadline | Date input
 
 | ❌ No
 
 | Must be today or future
 
 |
